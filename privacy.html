01처리 목적

오늘의낚시(이하 “서비스”)는 기상청·해양조사원·공공데이터포털의 관측·예보 데이터를 바탕으로 출조 적합도를 판정합니다. 이와 함께 SNS에 공개된 조황 후기를 출처가 검증되지 않은 참고 정보로 모아 지역·어종별 조황 동향을 파악합니다.

안전·출조 판정은 공공데이터와 규칙 엔진이 수행하며, SNS 게시물은 판정을 뒤집는 근거로 사용하지 않습니다.

02수집하는 항목

Meta가 제공하는 공식 API(Threads API, Instagram Graph API)를 통해, 낚시 조황과 관련된 검색어·해시태그에 해당하는 공개 게시물만 조회합니다.

출처조회 방식저장 항목
Threads조황 관련 키워드 검색게시물 ID, 게시물 링크, 작성자 사용자 이름, 본문, 작성 시각
Instagram조황 관련 해시태그 검색게시물 ID, 게시물 링크, 캡션, 작성 시각 (작성자 정보는 요청·저장하지 않음)
비공개 계정·비공개 게시물, 다이렉트 메시지, 팔로워·팔로잉 목록, 연락처, 위치 정보는 수집하지 않습니다. 이미지·영상 원본도 저장하지 않습니다.

수집한 본문에서 지역, 어종, 낚시 방식, 출조일 같은 조황 정보를 규칙 기반으로 추출해 함께 저장합니다.

03이용 방식

  • 조황 게시물인지(조황 / 모집·광고 / 기타) 분류하고, 지역·어종별 독립 출처 수를 집계합니다.
  • 집계된 요약 정보만 서비스의 조황 참고 자료로 활용합니다.
  • 게시물 원문이나 작성자 이름을 서비스 화면에 그대로 재게시하지 않습니다.
  • 수집한 정보를 광고, 프로파일링, 자동화된 개인 평가 목적으로 사용하지 않습니다.

04보관 기간

수집한 게시물 데이터는 수집일로부터 90일 동안 보관한 뒤 삭제합니다. 다만 이용자의 삭제 요청이 있거나 원본 게시물이 삭제·비공개로 전환된 것이 확인되면 그 이전에 삭제합니다. 요약 통계는 개별 게시물을 식별할 수 없는 형태로만 남깁니다.

05제3자 제공 및 처리 위탁

수집한 개인정보를 판매하거나 제3자에게 제공하지 않습니다. 데이터는 서비스 운영자가 관리하는 저장소에 보관되며, 외부 업체에 처리를 위탁하지 않습니다. 법령에 따라 수사기관 등이 적법한 절차로 요청하는 경우에는 예외로 합니다.

게시물 조회는 Meta Platforms(Threads·Instagram)의 API를 통해 이루어지며, Meta의 플랫폼 약관과 정책을 따릅니다.

06이용자의 권리와 행사 방법

게시물 작성자는 서비스에 자신의 게시물 데이터가 저장되어 있는지 확인하고, 열람·정정·삭제·처리 정지를 요청할 수 있습니다. 요청은 아래 데이터 삭제 요청 절차 또는 문의처로 접수하며, 본인의 게시물임이 확인되면 지체 없이 처리하고 결과를 알려 드립니다.

원본 게시물을 Threads·Instagram에서 삭제하거나 비공개로 전환하면, 확인되는 대로 서비스의 사본도 삭제합니다.

07데이터 삭제 요청

내 게시물이 서비스에 저장되었다고 생각되면 아래 방법으로 삭제를 요청해 주세요.

  1. 문의 이메일로 메일을 보냅니다.
  2. 제목에 “[데이터 삭제 요청]”을 적고, 본문에 삭제를 원하는 게시물 링크 또는 사용자 이름을 적습니다.
  3. 본인 확인을 위해 해당 SNS 계정에서 확인할 수 있는 방법(예: 계정 소개란에 안내하는 문구 게시 또는 DM 답장)을 요청드릴 수 있습니다.
  4. 확인 후 7일 이내에 저장된 데이터를 삭제하고 완료 결과를 회신합니다.
Meta 플랫폼을 통해 앱 연결을 해제한 경우에도, 위 절차로 요청하시면 해당 사용자와 관련해 저장된 데이터를 삭제합니다.

08안전성 확보 조치

  • API 접근 토큰과 앱 비밀 키는 소스 코드와 분리된 환경 설정 파일에 보관하고, 저장소에 올리지 않습니다.
  • 수집 데이터에는 접근 권한을 가진 운영자만 접근합니다.
  • 보관 기간이 지난 데이터는 복구할 수 없는 방법으로 삭제합니다.

09이 웹사이트 이용 시

이 처리방침 페이지는 정적 페이지로, 쿠키나 로그인, 사용자 추적 기능을 사용하지 않으며 방문자의 개인정보를 별도로 수집하지 않습니다. 단, 웹사이트 호스팅 사업자(GitHub Pages)가 서비스 제공을 위해 접속 기록을 처리할 수 있습니다.
